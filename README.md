# PigData — Plataforma de Espaços para Eventos (ACIT)

Índice da documentação do projeto. Os detalhes por área ficam em [`docs/`](./docs/). **Antes de qualquer implementação**, leia este índice e os arquivos das áreas envolvidas; depois registre o que foi feito em [`docs/IMPLEMENTACAO.md`](./docs/IMPLEMENTACAO.md).

## Como usar

1. Identifique quais partes do sistema a tarefa toca.
2. Leia os arquivos correspondentes abaixo (e o histórico recente em `docs/IMPLEMENTACAO.md`).
3. Implemente.
4. Atualize o(s) arquivo(s) da área + adicione uma entrada em `docs/IMPLEMENTACAO.md`.
