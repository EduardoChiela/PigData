# Métricas e impacto

## Objetivo

Provar o valor do projeto para ACIT, núcleos e comerciais: menos desistência, menos horas em consulta inútil, mais conversão.

## Indicadores-alvo

| Métrica | Para quê |
|---------|----------|
| Tempo médio até primeira resposta útil | Anti-desistência |
| Consultas manuais evitadas / horas economizadas | Argumento das +1.700 h/ano |
| Taxa consulta → reserva | Conversão |
| Desistência por demora (antes vs depois) | Impacto do mapa/agenda |
| % de agendas atualizadas na rede | Saúde do produto |
| Uso de alternativas de parceiros | Valor da rede |

## Estado da implementação

- Ainda sem dashboard/código de métricas.
- No piloto, mesmo medição manual (planilha) já valida a narrativa.
