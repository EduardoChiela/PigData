# Mapa e busca

## Objetivo

Descoberta **disponibilidade-first**: o usuário entra pela data e vê no mapa só (ou prioritariamente) o que está livre.

## Comportamento desejado

1. Entrada principal: “Quando você precisa?”
2. Mapa com indicadores: livre / parcial / indisponível
3. Filtros: capacidade, bairro/região, tipo de evento, preço
4. Clique no pin → perfil resumido → pedido/reserva

## Relação com outras áreas

- Consome agenda de [agenda-calendario.md](./agenda-calendario.md)
